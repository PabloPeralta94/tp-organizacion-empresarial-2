## Escenario
Escenario B – Análisis de Ventas de una Pequeña Empresa

## Descripción del proyecto
Análisis de un conjunto de datos de ventas comerciales para generar 
indicadores básicos que permitan interpretar el desempeño de la empresa.
Se calculan ventas totales, promedio diario, venta máxima y mínima, 
y evolución mensual de ventas.

## Dataset utilizado
Dataset de ventas simuladas con registros diarios (2024).
Columnas: id, sales_date, sales_amount.
Fuente: https://gist.github.com/khanusama20/ee33c2869dd5cf3cebdf020be1ca43f6

## Estructura del repositorio
- /datos → dataset CSV utilizado en el análisis
- /scripts → script Python de análisis
- /resultados → gráficos y tablas generadas

## Cómo ejecutar el script
1. Clonar el repositorio:
   git clone https://github.com/PabloPeralta94/tp-organizacion-empresarial-2.git
2. Abrir Google Colab y subir el repositorio
3. Ejecutar el script:
   %run scripts/analisis_ventas.py
